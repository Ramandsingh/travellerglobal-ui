# Sri Lankan Travel Agency App - Design Brief

## Design Overview
High-fidelity UI/UX design for a multi-role travel platform serving both customers and agent partners.

## Visual Identity

### Color Palette
- **Primary**: Emerald Green (#10B981, #059669)
- **Accent**: Gold (#F59E0B, #D97706)
- **Neutrals**:
  - Background: #FFFFFF, #F9FAFB
  - Text: #111827, #6B7280
  - Borders: #E5E7EB

### Typography
- **Font Family**: Inter, SF Pro Display (Sans-serif)
- **Hierarchy**:
  - H1: 32px/40px Bold
  - H2: 24px/32px SemiBold
  - H3: 20px/28px Medium
  - Body: 16px/24px Regular
  - Small: 14px/20px Regular

### Visual Style
- Minimalist, modern aesthetic
- Halal-friendly visual cues (subtle geometric patterns)
- High-quality imagery of Sri Lankan landmarks
- Clean spacing, card-based layouts
- Soft shadows and rounded corners (8-12px)

## Key Features

### 1. Multi-Role Dashboard
- Role switcher toggle (Customer View / Agent Partner Portal)
- Personalized widgets based on role
- Quick action buttons

### 2. Booking Pipeline (Agent View)
Status workflow:
1. **Lead** - Initial inquiry
2. **Booked** - Confirmed reservation
3. **In-Travel** - Currently traveling
4. **Completed** - Trip finished

### 3. Integration Points
- **WhatsApp Integration**: Quick contact buttons
- **SL Payment Gateways**: Local payment options (Dialog, Mobitel, Bank transfers)
- **API Aggregator**: Flight + Hotel + Transport unified search

### 4. Sri Lankan Elements
- Background imagery: Sigiriya Rock, Galle Fort, Tea Plantations, Beaches
- Local currency (LKR) display
- Multi-language support (English, Sinhala, Tamil)

## Screen Layouts

### Desktop (1440px+)
- Sidebar navigation (240px)
- Main content area with cards
- Right panel for quick actions/notifications

### Mobile (375px - 428px)
- Bottom navigation bar
- Collapsible filters/menus
- Touch-optimized buttons (44px minimum)

## Deliverables
1. Customer Dashboard (Desktop & Mobile)
2. Agent Partner Portal (Desktop & Mobile)
3. Booking Pipeline Screen
4. Search/Aggregator Interface
5. Payment Gateway Integration UI
