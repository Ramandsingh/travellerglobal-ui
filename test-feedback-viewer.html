Step 1: Go to your feedback page

https://ramandsingh.github.io/travellerglobal-ui/feedback.html

Step 2: Open Developer Console

Press F12 (or Cmd+Option+I on Mac)

Step 3: Go to Console tab

Step 4: Run these commands:

// View all feedback viewAllFeedback() // Export as JSON file exportFeedback() // Get count localStorage.getItem('designFeedback') ? JSON.parse(localStorage.getItem('designFeedback')).length : 0
